# Blood Management System (BMS) - Documentation

Welcome to the Blood Management System (BMS) project! This system streamlines the management of blood donations, stock, transfers, and user authentication for blood banks and related organizations. Below are visual representations of key features and interfaces within the system.

## Features
- Secure admin and user authentication
- Blood stock management and tracking
- Blood donation registration
- Blood transfer between locations
- Patient management
